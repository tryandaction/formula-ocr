# Private Real-Paper Benchmark Location

This directory is intentionally gitignored except for this orientation file.

Keep real source PDFs, rendered pages, and paper-derived formula crops here for local evaluation only. Verify source hashes before rendering, preserve the human ground truth independently from model output, and never upload samples whose `allowCloudUpload` policy is false.

The public repository uses `../synthetic-formula-v1` for distributable formula-image fixtures. Historical benchmark results and aggregate metrics remain versioned without requiring public redistribution of paper-derived image crops.
